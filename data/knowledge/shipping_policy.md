## [SHIP-001] 기본 배송 정책

```yaml
doc_id: SHIP-001
title: 기본 배송 정책
version: "3.2"
status: approved
effective_from: 2026-07-01
effective_to: null
category: 전체
supersedes: SHIP-002
approved_by: CS정책팀
last_updated: 2026-06-20
```

1. 기본 배송비는 **3,000원**입니다.
2. 결제금액(쿠폰·적립금 차감 후 실결제 상품금액 기준) **30,000원 이상** 주문 시 무료배송입니다.
3. 무료배송 기준은 **하나의 주문 단위**로 판단하며, 여러 주문을 합산하지 않습니다.
4. 부분 취소·반품으로 남은 결제금액이 30,000원 미만이 되면, 최초 면제된 배송비 3,000원이 환불금액에서 차감됩니다.
5. 해외 배송은 지원하지 않습니다.
6. 새벽배송·설치배송 상품은 각각 SHIP-006, SHIP-007의 별도 기준을 따릅니다.

## [SHIP-004] 출고 및 배송 소요 기간

```yaml
doc_id: SHIP-004
title: 출고 및 배송 소요 기간
version: "2.0"
status: approved
effective_from: 2026-01-01
effective_to: null
category: 전체
approved_by: 물류운영팀
last_updated: 2025-12-20
```

1. **평일 오후 2시 이전** 결제 완료 건은 당일 출고, 이후 결제 건은 다음 영업일 출고됩니다.
2. 출고 후 일반 택배 기준 **1~3 영업일** 내 도착합니다. (토·일·공휴일 제외)
3. 주문 상태는 `결제완료 → 상품준비중 → 배송중 → 배송완료` 순으로 변경됩니다.
4. 도착 예정일은 택배사 연동 정보 기준이며, 택배사 사정에 따라 변경될 수 있습니다.
5. 예약판매·주문제작 상품은 상품 상세페이지에 안내된 출고 예정일을 따릅니다.
6. 출고 예정일로부터 **3 영업일 이상 출고가 지연**될 경우 고객에게 알림톡이 발송됩니다.

## [SHIP-005] 제주 및 도서산간 추가 배송비

```yaml
doc_id: SHIP-005

status: approved
effective_from: 2026-01-01
effective_to: null
category: 전체
approved_by: 물류운영팀
last_updated: 2025-12-20
```

1. 제주 지역: 추가 배송비 **3,000원**
2. 도서산간 지역: 추가 배송비 **5,000원**
3. 추가 배송비는 무료배송 조건을 충족해도 별도 부과됩니다.
4. 제주·도서산간 지역은 배송 소요 기간이 **1~2 영업일 추가**될 수 있습니다.
5. 새벽배송·설치배송은 제주·도서산간 지역에서 이용할 수 없습니다.

```yaml
doc_id: SHIP-006

version: "2.1"
status: approved
effective_from: 2026-04-01
effective_to: null
category: 신선식품, 식품
approved_by: 물류운영팀
last_updated: 2026-03-25
```

1. 대상: 상품 상세에 `새벽배송` 표시가 있는 신선식품·식품

6. 배송 완료 시 사진과 함께 알림톡이 발송됩니다.

## [SHIP-007] 설치배송 정책

```yaml
doc_id: SHIP-007
title: 설치배송 정책
version: "1.4"
status: approved
effective_from: 2026-02-01
effective_to: null
category: 가전, 가구
approved_by: 물류운영팀
last_updated: 2026-01-20
```

1. 대상: 대형가전(냉장고, 세탁기, TV 65인치 이상 등), 조립·설치가 필요한 가구
2. 결제 후 **5~10 영업일** 내 설치기사가 해피콜로 방문 일정을 협의합니다.
3. 설치배송 상품은 배송비가 상품가에 포함되어 있습니다.
4. 엘리베이터 미설치 건물 3층 이상, 사다리차 필요 시 추가 비용이 현장에서 발생할 수 있습니다.
5. 방문 일정 확정 후 **방문 2일 전까지** 일정 변경 가능합니다.

## [SHIP-008] 배송지 변경 및 배송 보류

```yaml
doc_id: SHIP-008
title: 배송지 변경 및 배송 보류
version: "1.2"
status: approved
effective_from: 2026-01-01
effective_to: null
category: 전체
approved_by: CS정책팀
last_updated: 2025-12-20
```

1. 배송지 변경은 주문 상태가 **`결제완료` 또는 `상품준비중`** 일 때만 가능합니다.
2. `배송중` 상태부터는 배송지 변경이 불가하며, 택배사에 직접 요청해야 합니다. (택배사 정책상 불가할 수 있음)
3. 제주·도서산간으로 변경 시 추가 배송비가 발생합니다.
4. 배송 보류(수령일 지정)는 최대 7일까지 가능하며, 신선식품은 불가합니다.

## [SHIP-009] 배송 사고(분실·파손·오배송) 처리

```yaml
doc_id: SHIP-009
title: 배송 사고 처리
version: "2.0"
status: approved
effective_from: 2026-03-01
effective_to: null
category: 전체
approved_by: CS정책팀
last_updated: 2026-02-20
```

1. 배송완료로 표시되었으나 수령하지 못한 경우, 배송완료일로부터 **7일 이내** 신고해야 합니다.
2. 파손·오배송은 수령 후 **7일 이내** 사진과 함께 접수합니다.
3. 분실 신고 접수 시 택배사 확인(최대 3 영업일) 후 재발송 또는 전액 환불합니다.
4. 배송 사고 처리는 **상담원 확인이 필요한 사항**으로, 자동응답으로 환불·재발송을 확정하지 않습니다. (MAN-001 참고)

## [SHIP-010] 2026 추석 연휴 배송 안내

```yaml
doc_id: SHIP-010
title: 2026 추석 연휴 배송 안내
version: "1.0"
status: expired
effective_from: 2026-09-20
effective_to: 2026-10-12
category: 전체
approved_by: 물류운영팀
last_updated: 2026-09-15
```

1. 2026년 9월 23일(수) ~ 10월 7일(수) 결제 건은 택배사 물량 증가로 배송이 **최대 5 영업일** 지연될 수 있습니다.
2. 연휴 기간(9/24~9/27) 중에는 출고가 중단됩니다.
3. 연휴 기간 배송 지연은 배송 지연 보상(CPN-004) 대상에서 제외됩니다.
