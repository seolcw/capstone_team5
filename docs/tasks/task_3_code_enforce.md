# [작업 3] 프롬프트 대신 코드로 강제하기 (v1+ 4차) — AI에게 붙여 넣는 프롬프트

> 아래 `---` 사이 전체를 복사해서 AI에게 그대로 붙여 넣으세요.

---

너는 지금부터 나의 개발 도우미야. 나는 컴퓨터공학 전공이 아니고 AI·프로그래밍도 잘 몰라.
**모든 단계를 쉬운 말로 설명**하고, 코드는 **복사해서 바로 쓸 수 있는 완성본**으로 줘.
명령어는 어느 폴더에서 실행하는지, 정상 결과가 어떤 모습인지 같이 알려줘. 단계별로 하나씩 진행하고, 내가 결과를 붙여 넣으면 확인해 줘.
코드를 고치기 전에 **먼저 내가 `cs_agent/v1_plus.py` 전체 내용을 보여주도록 요청**해 줘 (추측해서 쓰지 말 것).

## 1. 배경
- 우리는 이커머스 고객 상담 AI 챗봇을 만들고 있어. `cs_agent/v1_plus.py` 가 현재 버전(v1+)이고,
  LLM(qwen2.5-14b)이 도구(Python 함수)를 골라 부르는 **Agent loop** 구조야.
- v1+ 는 이미 "도구가 LLM 에게 돌려주는 결과를 코드로 검사"해서 틀린 정책 안내를 0건으로 만들었어.
- 남은 문제: 시스템 프롬프트에 규칙을 써 놔도 **LLM 이 자주 무시**함. 평가에서 실제로 본 실패:
  | 케이스 | 고객 질문 | 실패 모습 |
  |---|---|---|
  | PUB-014 | 마우스 배송 엄청 늦게 왔는데 보상 같은 거 없나요? (C0013) | 주문번호를 **지어내서** get_shipment → NOT_FOUND → 고객에게 "주문번호 알려주세요" |
  | PUB-022 | 울릉도인데 수건 언제 도착하나요? (C0021) | 위와 같음 |
  | PUB-013 | 제주도인데 배송비 왜 더 붙었어요? 그리고 언제 와요? (C0012) | 배송비만 답하고 **주문 조회를 안 해서** 도착일 누락 |
  | PUB-002 | 주문한 거 언제 와요? (C0002) | 진행 중 주문 2건 중 1건만 안내 |
- 교훈: **꼭 지켜야 하는 동작은 프롬프트가 아니라 코드로 강제**해야 한다. 이게 내 작업이야.

## 2. 할 일 (`cs_agent/v1_plus.py` 만 수정, 다른 파일은 eval 실행 외 수정 금지)

### 2-1. 주문번호 추측 차단 (코드)
`_get_order`, `_get_shipment` 에서 결과가 `NOT_FOUND` 이면, hint 만 주지 말고 **코드가 직접 `_list_orders(session)` 결과를 붙여서** 돌려줘:
```python
return {"error": "NOT_FOUND", "hint": "추측한 주문번호입니다. 아래 고객 주문 목록에서 골라 다시 조회하세요.",
        "고객_주문목록": _list_orders(session)}
```
기대 효과: LLM 이 되묻지 않고 목록에서 올바른 주문을 찾음 (PUB-014, PUB-022).

### 2-2. 주문·배송 질문이면 주문 목록을 미리 넣어 주기 (코드)
질문에 `주문, 배송, 택배, 도착, 언제 와, 왔어, 보상, 늦게, 지연` 중 하나라도 있으면,
Agent loop 시작 전에 코드가 `_list_orders(session)` 를 실행해서 **첫 user 메시지 뒤에 참고 정보로 넣어** 줘:
```python
messages.append({"role": "user", "content": "[시스템 참고: 고객 주문 목록]\n" + json.dumps(rows, ensure_ascii=False)})
```
Trace 에도 남기기: `tr.tool("list_orders", {"auto": True}, rows)`.
기대 효과: 도착일 누락(PUB-013), 진행 중 2건 중 1건만 안내(PUB-002) 감소.

### 2-3. 배송 지연이면 보상 정책을 자동 첨부 (코드)
`_get_shipment` 결과에서 `is_delayed` 가 True 면, 승인된 보상 정책 `CPN-004` 요약을 결과에 같이 넣어 줘
(`from .common import DOC_BY_ID` 후 `DOC_BY_ID["CPN-004"]["text"]` 앞부분 400자).
`delay_compensation` 값(이미 지급됐는지·금액)이 있으면 그것도 그대로 포함.
기대 효과: "보상 2,000원 자동 지급" 누락 감소 (PUB-004, PUB-014).
